## Purpose

- Learn reinforcement learning concepts through practical implementations.
- Understand the logic behind RL algorithms by reading and experimenting with the code.
- Explore compatibility with modern Python versions.
- Experiment with the implementations as part of my ongoing learning journey.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/chauhan463/Dissecting_RL.git
cd Dissecting_RL
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the dependencies required by the example you want to run, then execute the corresponding Python script.
